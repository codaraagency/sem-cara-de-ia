# Política de Privacidade — Sem Cara de IA

Sem Cara de IA é um plugin/skill que roda inteiramente dentro do produto de IA que você já usa (Claude, ChatGPT, Codex ou similar). Ele não opera servidor próprio, não exige cadastro e não coleta, armazena ou vende nenhum dado pessoal.

## O que acontece com o texto que você edita

O texto que você cola ou pede para editar é processado pelo produto de IA que está executando o skill — Claude, ChatGPT, Codex ou outro. Esse processamento está sujeito à política de privacidade desse produto, não à nossa: o projeto em si não vê, não armazena e não tem acesso a esse conteúdo.

## Logs de acesso ao projeto

Acessar o repositório no GitHub ou qualquer página relacionada ao projeto pode gerar os registros padrão de acesso (logs de servidor, analytics) de acordo com as políticas do GitHub e das ferramentas usadas para hospedar o projeto.

## Contato

Dúvidas sobre esta política podem ser abertas como issue no repositório do projeto.
