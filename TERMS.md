# Termos de Uso — Sem Cara de IA

Sem Cara de IA é um fluxo de edição de texto de código aberto, distribuído sob a licença MIT (veja [LICENSE](LICENSE)).

## O que o skill faz e o que ele não faz

O skill fornece sugestões editoriais e aponta padrões de escrita que costumam soar genéricos ou artificiais em português. Ele não garante que um texto vai parecer "100% humano", nem que vai passar despercebido por qualquer detector específico de IA. Revise sempre o resultado antes de publicar ou usar como base para qualquer decisão.

Este projeto não oferece orientação jurídica, médica, financeira ou de qualquer outra área profissional regulada — as sugestões são apenas sobre estilo de escrita.

## Garantias

O software é fornecido "como está", sem garantias de qualquer tipo, conforme descrito na licença MIT.

## Serviços de terceiros

O uso de produtos de IA de terceiros (Claude, ChatGPT, Codex, GitHub e outros) para rodar este skill está sujeito aos termos de uso dessas respectivas empresas.
