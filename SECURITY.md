# Política de segurança

## Escopo

Sem Cara de IA não opera servidor próprio. Problemas de segurança podem envolver o pacote distribuído, arquivos do repositório, workflow de release ou instruções de instalação.

Não use issues públicas para relatar uma vulnerabilidade que exponha pessoas, dados ou credenciais.

## Como reportar

Abra uma [Security Advisory privada no GitHub](https://github.com/codaraagency/sem-cara-de-ia/security/advisories/new) com:

- descrição e impacto;
- versão afetada;
- passos de reprodução mínimos;
- evidência que não contenha segredos;
- sugestão de correção, se houver.

Se não conseguir usar esse canal, abra uma issue pública apenas para pedir um canal privado. Não inclua detalhes técnicos do problema nessa issue.

## Versões suportadas

| Versão | Suporte |
| --- | --- |
| 1.1.x | Sim |
| < 1.1.0 | Não |

## Divulgação

Depois da correção e da publicação de uma versão afetada, o repositório documentará o impacto e os passos de atualização em uma advisory ou release note.
